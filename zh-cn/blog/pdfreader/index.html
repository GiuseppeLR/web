PDF Reader for macOS

Jul 29, 2026 · Swift macOS SwiftUI

项目简介

PDF Reader for macOS 是一个功能丰富的 macOS 原生 PDF 阅读器，使用 SwiftUI + PDFKit 构建。它追求系统预览的流畅度和 Acrobat Reader 的功能完整度。

功能特性

阅读体验

  • 多显示模式：单页、双页、连续滚动
  • 流畅缩放：支持快捷键和手势缩放
  • 全屏阅读模式：沉浸式阅读体验
  • 页面间距调整：自定义页面间距
  • 平滑滚动：优化的滚动性能

导航与搜索

  • 大纲视图：PDF 目录快速导航
  • 缩略图侧边栏：拖拽重排页面
  • 全文搜索：高亮搜索结果，上下文预览
  • 书签管理：添加、编辑、跳转书签
  • 页面跳转：快速跳转到指定页面

PDF 编辑

  • 标注工具：高亮、下划线、删除线
  • 便签笔记：在任意位置添加便签
  • 橡皮擦：快速删除标注
  • 颜色选择：黑/蓝/红 三色标注
  • 页面旋转：顺时针旋转页面
  • 页面删除：删除不需要的页面

高级功能

  • 页面提取/导出：导出指定页面范围
  • PDF 合并：合并多个 PDF 文件
  • 页面插入：从其他 PDF 插入页面
  • PDF 压缩：压缩导出减小文件体积
  • 图片提取：提取 PDF 中的图片
  • 页面快照：导出页面为图片
  • 签名/盖章：鼠标绘制签名并放置到文档
  • 文本复制：复制选中文本
  • 打印支持：完整打印功能

界面设计

  • 玻璃质感：macOS 原生毛玻璃效果
  • 深色模式：自动跟随系统
  • 主题色：可自定义应用主题色
  • 设置面板：外观、阅读、显示、行为、搜索等 6 大分类设置

技术栈

  • SwiftUI - 声明式 UI 框架
  • PDFKit - PDF 渲染与标注
  • AppKit - 打印、文件面板等系统集成
  • @Observable - 现代 Swift 观察模式
  • UserDefaults - 设置持久化

系统要求

  • macOS 14.0 (Sonoma) 或更高版本
  • Xcode 16.0+（如需自行编译）
