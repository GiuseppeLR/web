NJTech Timetable

Jul 29, 2026

Flutter Mobile

About

NJTech Timetable (南工课程表) is a course schedule management tool designed for Nanjing Tech University students. It supports academic system import via WebView, XLS file import, manual course management, course reminders, schedule sharing, dark mode, and course conflict detection. Built with Flutter/Dart, with Kotlin and SwiftUI native integrations.

Features

  • WebView import from academic system
  • XLS file import
  • Manual add, edit, delete courses
  • Current week and semester start date settings
  • System notification reminders before class
  • Schedule import/export for sharing
  • Dark mode with system auto-switch
  • Course conflict detection
  • Auto backup before import with restore
  • In-app feedback

Tech Stack

  • Flutter 3.x / Dart 3.x
  • Android (Kotlin)
  • iOS (SwiftUI)
