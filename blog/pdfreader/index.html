PDF Reader for macOS

Jul 29, 2026
Swift macOS SwiftUI

About

A feature-rich native macOS PDF reader built with SwiftUI + PDFKit. It strikes a balance between the smoothness of Apple's Preview and the feature completeness of Acrobat Reader.

Features

Reading Experience

  • Multiple display modes: single page, double page, continuous scroll
  • Smooth zoom with keyboard shortcuts and gestures
  • Full-screen reading mode
  • Adjustable page spacing
  • Smooth scrolling with optimized performance

Navigation & Search

  • Outline view for quick PDF table of contents navigation
  • Thumbnail sidebar with drag-to-reorder pages
  • Full-text search with highlighted results and context preview
  • Bookmark management: add, edit, jump to bookmarks
  • Quick page jump to any page number

PDF Editing

  • Annotation tools: highlight, underline, strikethrough
  • Sticky notes: add notes anywhere on the page
  • Eraser to quickly remove annotations
  • Color selection: black, blue, red
  • Page rotation (clockwise)
  • Page deletion

Advanced Features

  • Page extraction/export: export specific page ranges
  • PDF merge: combine multiple PDF files
  • Page insertion from other PDFs
  • PDF compression for smaller file sizes
  • Image extraction from PDFs
  • Page snapshot: export pages as images
  • Signature/stamp: draw signatures with mouse and place on document
  • Text selection and copying
  • Full print support

UI Design

  • macOS native frosted glass effect
  • Dark mode with automatic system follow
  • Customizable accent color
  • Settings panel with 6 categories: Appearance, Reading, Display, Behavior, Search

Tech Stack

  • SwiftUI - Declarative UI framework
  • PDFKit - PDF rendering & annotation
  • AppKit - Printing, file panels, system integration
  • @Observable - Modern Swift observation pattern
  • UserDefaults - Settings persistence

System Requirements

  • macOS 14.0 (Sonoma) or later
  • Xcode 16.0+ (for self-compilation)
